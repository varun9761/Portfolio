# Varun Kumar Portfolio

A modern personal portfolio website for **Varun Kumar**, built to showcase projects, skills, resume, and contact details in a polished responsive layout.

The portfolio uses an iOS-inspired liquid glass interface, smooth animations, dark/light mode, project cover cards, technology icons, and a resume download option.

## Features

- Responsive portfolio layout for desktop and mobile
- iOS-style liquid glass UI
- Light and dark mode toggle with saved preference
- Animated hero typing effect
- Project showcase with cover images
- Technology stack icons with hover labels
- Resume download button
- Contact form section
- Social links for Email, LinkedIn, and GitHub

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Devicon icons
- Google Fonts

## Projects Showcased

- **ShareBite**: A full-stack surplus food recovery & NGO redistribution platform connecting restaurants, caterers, and food donors with nearby NGOs.
- **Planora**: A smart travel planning and dynamic itinerary engine with weather forecasts and destination discovery.
- **Expense Trail**: A full-stack personal finance and budget management web app for tracking expenses and visualizing spending patterns.
- **Word Scramble**: An interactive browser puzzle game built with HTML, CSS, and JavaScript.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/varun9761/Portfolio.git
```

Open the project folder:

```bash
cd Portfolio
```

Run the website by opening `index.html` in your browser.

No build step or package installation is required.
